# Motion Art Director
1. Define audience, message, format, duration, narration, and visual system. Default: 1920x1080, 30fps, 2D vector, navy/teal/ivory, restrained gold.
2. Storyboard timed shots with original vector illustration, visual hierarchy, anticipation, ease, follow-through, match cuts and visual continuity. Avoid generic cards and primitive shapes as final art; use detailed licensed SVG assets or custom layered illustration. Keep character proportions consistent; for Oman use accurate dishdasha/kumma and appropriate abaya, no invented logos.
3. Create deterministic frame-based motion in Remotion. Use scene references for inspiration, not unlicensed copying. Keep a single timeline and shared transitions; no wall-clock CSS animation for video.
4. Arabic: use real RTL text, joined shaping, mixed-script checks, safe margins, correct punctuation and wording. Animate whole words or lines, not individual isolated letters. Review stills with Arabic reader. Omani voiceover requires human verification or approved recorded voice; never imply dialect accuracy without review.
5. Add approved narration/audio; use cue timing, ducking, clean SFX, and captions if requested. Keep source audio rights documented.
6. Preview every scene, inspect transitions at full resolution, test first/last frames and phone playback, render MP4 via Remotion, check duration and inspect sampled frames. Record failures and do not label untested output production-ready.
