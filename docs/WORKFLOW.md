# Workflow
- Run `npm install`, `npm test`, `npm run studio`. Preview the example at `npm run preview` (Vite). `npm run render` writes the sample MP4.
- Optional references: `npm run import:catalog -- remotion-skills remotion-scenes motion-canvas`. Imported repositories are ignored by git. Check each license, lock commit IDs for real productions, retain notices. Do not bundle third-party assets by default.
- GitHub Actions can run the sample render and upload MP4 as an artifact. Enable Actions, then run Render sample from the Actions tab. GitHub Pages can host the preview; it cannot execute the Node/Chromium video renderer. Use a cloud terminal/Codespaces from iPhone Safari, or GitHub Actions. No desktop graphics app needed, but a Node environment is required.
- Sample is original SVG animation with no audio; add approved voiceover and properly licensed illustrations for a production film. Font fallback may vary; bundle an approved Arabic font for consistent rendering and inspect Arabic shaping.
- Remotion uses a special license; review current terms before government or organizational work. Other repos have independent terms; catalog is not permission to reuse.
